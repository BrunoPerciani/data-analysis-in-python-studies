# Python Studies through DataCamp Practice 🐍📊

This repository is my personal learning log for studying **Python for data analysis** through hands on practice. It contains the scripts I developed while completing the **Data Analyst in Python** learning track, with a focus on programming fundamentals, data manipulation, statistics, and visualization.

The goal of this repository is to consolidate essential Python concepts, analytical thinking, and practical problem solving skills by keeping an organized collection of scripts built throughout my learning journey.

## 📌 About this repository

This repository follows a progressive learning path, starting with Python fundamentals and gradually advancing toward data analysis applications. The scripts were written as part of guided exercises, practical lessons, and course activities, allowing me to strengthen both my programming logic and my ability to work with data.

Rather than focusing only on isolated syntax examples, the emphasis is on **using Python to explore datasets, manipulate information, create visualizations, and support analytical reasoning**, reflecting a more practical and applied learning experience.

## 📚 Repository structure

The repository is organized according to the main topics covered throughout the track. It currently includes materials related to Introduction to Python, Intermediate Python, Data Manipulation with Pandas, Data Joining with Pandas, Introduction to Statistics in Python, and Introduction to Data Visualization with Seaborn.

Each folder represents a specific course or stage of the learning path. Inside them, the scripts register exercises, examples, and practical applications developed during the studies.

## ▶️ How to use

The files can be viewed directly on GitHub or executed locally in any Python environment. To run the scripts, it is recommended to have Python installed, as well as libraries such as Pandas, NumPy, Matplotlib, or Seaborn whenever required by the exercises.

A code editor such as Visual Studio Code, PyCharm, or Jupyter Notebook can also be useful for exploring and testing the scripts.

## 📝 Notes

This is a **study focused repository**. Its main purpose is to document my progress, reinforce key concepts, and serve as a long term reference for future academic, technical, and professional projects involving Python and data analysis.

As I continue learning, new folders and scripts may be added to reflect additional topics and more advanced applications.
